第一章　配分语综述

统合教程第一册　第一章

配分语是由二项式顺铂于 2026/7.29–7.31 三天时间设计出的极简人造语言。目的是用更少的词汇、更简单的学习难度、更自然的语法构建世界最简单的语言的一次对极简主义的践行。

字母与读音

配分语只有 16 个基本字母，坚持一音一标。下面是 4×4 字母表。

ptkf shmn lwya eiou

提示

n 是比较特殊的辅音，它可以作一个音节的结束音。

在后文，辅音可能会以 C 代表，元音以 V 代表。

n 可能专门表示字母 n 位于结束音（音节末尾）时的发音。无辅音以 ø 代表。

辅音

下表中，前侧的为标准的读音，后侧标星号的为不标准但可接受的读音。

拓展

虽然 l 的标准发音为「齿后鼻音」，但社区中大家热衷把它读作边音（汉语与英语中的「l」）。

发音位置齿前齿齿后

辅音部分，比较大的特点是爆发音、摩擦音的清浊不分。

结音

结音即结束音，此音节部分的字母只有一个 n，但可以根据后一个音节读什么自由切换读音。

提示

saŋta 里的 ŋ 就是汉语的后鼻音 ng。

写法通常读法
sanmasamma
sansasansa
sankasaŋka

思考

想一想：n 在这些音前为何会变读为不同的音？试着发音后总结规律，这个变读规则复杂吗？

音节与合法

每个音节必须遵循（辅音）+ 元音 +（鼻音）的规则。故配分语一共有四种音节模式：

Va
CVnpan
Vnan

配分语所有的词都是单音节的，因此对中文使用者很友好。

拓展

我们之后可能会学到单个 n 所成的特殊语气词 NN（读作嗯的鼻音部分），它不属于音节。所以进而不属于词的范畴。

配分语允许连读，但前提是清晰，连读速读不作规范。

书写方式

配分语共有两种最常见的书写系统：拉丁字母写法 walin、与象形字母写法 welin。它们都是从左往右写的。

拉丁写法在 7/29 日创建并完善，象形字由 7/30 开始制作，并于 9/6 完全完工。两者都是配分语重要的书写方式。

拉丁写法
mi yo fon e pe fon. hi wa yo e ,ni an pe!
象形字写法
mi yo fon e pe fon. hi wa yo e ,ni an pe!

拉丁写法

思考

walin 的意思是“单个的文字”，请思考为什么取这个名字。

拉丁写法使用拉丁字母进行书写，就如前面课时所使用的一样。

省写

配分语的拉丁写法可以省写空格等，学到时会介绍。

象形写法

象形写法因为是“音节文字”，每一个象形字表示一个音节（一般是 1~2 个字母），故叫 welin（两个字母的文字）。

象形写法也由 LJG 发明引入，字形渊源可由下面几种来：

字形来源例说明
事物的象形pe意思是“好的”，像笑脸。
事物部分的象形fi意思是“人”，像人头。
拉丁字母的变形lo和意思无关，这是从这个单词首字母“L”变形而来的。
以语法作用为核心a语法作用是“主谓连接”，是通常句子的第一处连接，故一条竖线。
道本图的衍生wo既是 W 的变形，也是道本语 wile 的道本图。
汉字的衍生ya意思是“太阳”，这像中文的“日”。
约定俗成的符号na形状是一个数学的“无限”符号，表示“所有”的意思。

知道象形字的来源，那么背诵也将变得更简单更自然啦。

象形系统发展

配分语的象形文字也几经波折，这里列举一下几个重要的发展节点。

7/14配分语最开始的音系和词汇的分类较为混乱，词语的类聚和对立尚未形成。
7/15配分语的第一次词汇重大变化，出现了词汇在读音上的严格对立，但一些写法不是特别方便。
8/2词汇大修改后的修订字形，确定了字形表的基本结构。
8/5由 Nefi 制作的配分语字体 fesenpefon 的字形表。
8/25配分语的字形基本完善，和现在使用的字形系统只有很小程度的不同。
8/30配分语的 fefenpefon 字体字形一览，也是本教程选择的字体，收录了纪念字形、旧字形、其余写法字形和复合字，代表着配分语的象形书写体系的基本封闭。

提示

虽然配分语的象形字形设计是从 7/14 开始的，但它最初并非为其服务的，在 7/30 时才正式引进使用。

n 形式写法

敏锐的你可能发现，在上一页中的字形表中的字形没有任何 CVn 或 Vn 结构的音节。

这是因为对于配分语的词汇系统，象形书写系统有独特的调整。

拓展

我们之后会在词汇介绍和后续学习中学到：

  • 配分语的 -n 形式的词汇总是和无结尾 n 的词汇在词义上有联系。

所以配分语的象形系统并未向 -n 词多做字形。

n 形式即为 CV 或 V 音节后面加 n 后组成的 CVn 或 Vn 音节。

配分语象形字的 n 形式一般为在无 n 结尾形式下面加短横或者点。如：

fofo 意思为嘴巴／食物／吃
fonfon 和 fo 也有词义上的联系：意为语言／演讲／说……

象形字体

配分语的象形字体有 Kuhunpefon、Fesenpefon、Fefenpefon、Tiyonpefon、Inkupefon、Fefapefon、Nesonpefon、Nokupefon、Sosopefon、Kifinpefon、Latinpefon 等。

截至教程编写此时，字体创作者一共有：LJG、Nefi、Ouyang、Billynike、At_Yeso。

输入法

配分语的输入法主要有 fastinp、2_9、4*4、tsn、12 等方案。

通过使用输入法进行搭载的 Keyman 软件，你可以在手机与平板上实时输入象形字等，详情与教程请看二项式顺铂的输入法宣传视频。

词汇

配分语的词汇系统非常简单，整个语言只有 58 个词！

具有以下特征：

  • 词汇量稀少，都是单音节
  • 无词源
  • 词以类聚，在字形表上很有体现

总体来看，这个“词表”的分类方式为以词类别分类，之后我们还会学到以词性分类或以词形状分类等的分类方式。

提示

如果你对长文本的阅读兴趣很差，可以跳过这几段，这对配分语的学习影响不大。

我来解释一下这些词的分类依据：

  • 相对词

    相对词是指在此类词中 a 结尾的词总是和 e 结尾的词相对，如 pa 的意思是“坏”，pe 则是“好”。

    拓展

    相对词的之前名字为“ae 类词”“相对形容词”，不选用的原因是“ae 类词”不包括 a/e 本身，而“相对形容词”有点框住词性的意味。

    事实上，配分语的 a 结尾的词总是和 e 结尾的词有对立，就算是语法词的 a 和 e 也一样。

  • 箭头词

    箭头词的来源是指 pi、po、pu 的旧字形是三个箭头，如 ni2 ni ni6。虽然在新版改成了这样的字形，叫法不变。表示的是事物转化的规律，对应“去／保持／来”。

  • 性质词

    性质词指它描述事物的作用和直观特征，其中根据首字母还能细分为 t 类性质词和 k 类性质词。

    这样的细分方法有意义，t 类性质词表示事物在一个事件中扮演什么角色的宏观要素，ti/to/tu 的意思分别是时间／工具／地方；k 类形容词，则表示事物的直观性质，ki/ko/ku 的意思分别是气体／液体／固体。

  • 代词

    拓展

    在此书下个章节就会学到“i 类词省略”，可见其重要性。

    代词中一共有 5 个，因为都以 i 结尾，之前的语法书中或称之为“i 类词”，现在也有使用这个别名的。从左到右分别代表人／他／你／我／这，其中“他”也可以代表它／她，等价。

  • 感官词

    感官词都以 o 结尾，故也有称“o 类词”。它包括嘴-手-心-耳-眼-面，在描述感受时很重要。

  • 概念词

    概念词还称为“u 类词”“基本概念词”或“基本词”，指的是除了 o 类词外其他常见的以动词为出发点的概念，如“拿、交易”等。

  • 反相对词

    反相对词只有一个 wi，表示“中等”的概念，刚好是以形容词为出发点的唯一一个不能形成相对概念的词，但这不代表它不重要。

  • 常见拟声

    常见拟声是 n，类似汉语思考时的嗯……，是具有语法效应的拟声词，因为不成一个音节，不称作“词”，常放在字形表的左上角。

    提示

    拉丁写法可以是 n 或 NN，因为字体原因，推荐使用 NN 来表达。在配分语的 Fefenpefon 象形字体中，我将其分配到了 NN 的码位。

  • 语法词

    语法词指的是以语法效应为出发点的词，有专为语法作用的虚语法词，也有存在常见实意的实语法词。

n 形式

我们来正式讲讲词汇中的 n 形式吧。

每个无 n 结尾的词简称为无 n 词，都有其对应的有 n 结尾的词简称为n 词。它们之间的意思一定有简单自然的映射关系（一些最基本的语法词除外，对应逻辑可能在现在的学习阶段不太好理解）。可以分为以下几类：

方式一句话规律例（无 n 词 → n 词）
延申同一东西的两面，n 词的层次通常更高fo 吃 → fon 说（介质仍是嘴巴）
对立两者正好相反ni 这 → nin 那
类推由相似的联想推得ki 气体 → kin 火（火势也向上蔓延）
深化同一个方向，程度更深i 转、变得 → in 但是、反转
先后先有前者，后有后者te 下、压 → ten 压爆、反抗
中例取常见例子的特点ko 液体、水 → kon 混乱的（取“酒”的特点）
抽象从具体而抽象ke 坑、容器 → ken 安全、舒适

拓展

如果不要求这么精细的分类（很多情况下，一个无 n 词与 n 词的词组是可以用不止一种方式进行解释的），则可以简单分为四类：

  • 相反：对立和一些延申；
  • 联想：延申、类推、中例；
  • 沉下：深化、先后；
  • 抽象。
